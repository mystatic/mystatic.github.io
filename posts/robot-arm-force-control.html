Part 01 · 核心四大接触交互范式与空间翻译地基
为什么力控、柔顺、阻抗、导纳听起来一团乱麻？它们到底是谁包含谁？
辈分总纲（破除概念混乱）：这些名词根本不是并列关系，而是包含关系——不碰外物时用纯刚性位置控制；一旦要触碰环境，只要管理接触力或遇阻退让，统称广义力控家族。广义力控往下分三大支：① 柔顺控制（像弹簧一样让步，含被动真弹簧，以及靠算法的阻抗控制与导纳控制双胞胎）；② 力位混合控制（一面控死压力、一面走准路线）；③ 重力补偿与零力拖动示教（太空失重悬停学艺）。

1机械臂四大核心控制范式逐一拆解

Paradigm 01 · Rigid Position (CSP) 纯刚性位置控制 —— “闭眼走正步的硬汉”
口诀：命令我去 50.0 cm，黑板挡在 49.8 cm 我也照样往死里怼！

生动比喻：6 个关节全部跑高增益 CSP 周期同步位置模式。在空气里挥舞（激光切割、喷涂、隔空码垛）快准狠；但只要拿它去擦黑板或插充电枪，环境偏歪 2 毫米 就会把电流拉满硬撞，轻则过流保护停机，重则顶穿工件。

适用边界：工件定位极其精准、无需与未知环境发生刚性挤压的非接触作业。

Paradigm 02 · Impedance Control (主动柔顺 · 哥哥) 阻抗控制 —— “测位置偏差，算回弹力气”
口诀：把我推偏 2 厘米，我就按弹簧公式温柔回敬 10 牛顿力！

生动比喻：就是上篇 MIT 模式的全臂空间升级版。底层电机直接跑 CST / MIT 力矩控制，不需要装昂贵的腕部力传感器——外力推偏末端时，编码器测出位置差 Δx，控制器算出虚拟弹簧力并直接转化为电机电流。

典型场景：人形机器人全身交互、四足机器狗落地缓冲、准直驱（QDD）双臂柔顺抓取。

Paradigm 03 · Admittance Control (主动柔顺 · 弟弟) 导纳控制 —— “测外力大小，改目标位置”
口诀：我骨子里是位置硬汉，但手腕贴了痛觉神经，一碰我就光速缩手！

生动比喻：传统工业臂减速比高达 100:1，齿轮极涩根本推不动，电机也只认死板的 CSP 位置指令。于是在手腕加装一颗六维力传感器：手指推手腕 5 牛顿 → 传感器报信 → 大脑立刻把发给位置电机的目标点往后挪 2 厘米，靠主动退让“演”出了弹簧感。

典型场景：传统工业六轴臂改装精密轴孔装配（插齿轮/装轴承）、重型工件柔顺对接。

Paradigm 04 · Hybrid Force / Position 力位混合控制 —— “擦黑板与削苹果大师”
口诀：垂直桌面方向死保 15 牛顿按压力，平行桌面方向精准走出 S 形！

生动比喻：纯弹簧柔顺有个缺点——桌面凸起的地方按得重、凹陷的地方按得轻。力位混合控制把三维空间正交切开：法向（垂直表面）交给纯力控闭环死守恒定压力；切向（沿表面）交给位置闭环精准走轨迹。

典型场景：3C 手机外壳曲面抛光、焊缝恒力打磨、医疗超声探头贴合人体自动扫查。

2从“单电机角度”到“手掌三维坐标”的 3 位数学翻译官

Translator A · FK

正运动学（Forward Kinematics）

“知关节角 → 算手掌在哪”：读取 6 个电机编码器角度 q₁~q₆，顺着连杆长度用三角几何一路算出末端三维坐标 (x, y, z)，唯一确定。

Translator B · IK

逆运动学（Inverse Kinematics）

“知目标点 → 反推各电机角度”：已知水杯在 (x, y, z)，每 1ms 反解出 6 个电机各自该去几度并喂给 CSP 驱动器，存在多解或够不着无解。

Translator C · Jacobian Jᵀ

雅可比转置（空间力与关节力矩桥梁）

力控灵魂公式 τ = Jᵀ(q) · F：直接把“想让手掌在笛卡尔空间输出的三维力 F”，精准换算成“6 个电机各自该出的扭矩 τ”！

Part 03 · 进阶灵魂三连问深度拆解
为什么传统工业臂做不了纯阻抗？零力拖动示教怎么写代码？“奇异点抽风”又是什么？
从算法框图到真机落地的三道鸿沟：真机调试时，90% 的困惑都源自物理硬件与几何边界——① 减速比平方效应锁死了传统工业臂的反向驱动能力；② 重力与摩擦辨识精度决定了零力拖动的手感上限；③ 雅可比降秩分母归零是机械臂在奇异点突然暴走甩尾的真凶。
追问 1 阻抗控制连力传感器都不用买，为什么传统工业机械臂不干脆全用阻抗控制？

核心卡点在于减速器（Gearbox）的反向驱动性（Backdrivability）！电机转子反射到关节输出端的等效惯量与减速比 N 的平方成正比，外加谐波柔轮极高的启动静摩擦死区：

# 电机转子反射到连杆端的等效惯量公式（N 为减速器减速比）：
I_reflected = N * N * I_rotor

# 路线 A：具身智能 QDD 准直驱行星关节（N = 6 ~ 10）
N = 8   -> 惯量仅放大 64 倍，静摩擦 < 0.3 N·m，外力推手腕顺畅传回转子，电流环直接精准控力！

# 路线 B：传统工业机械臂 谐波 / RV 减速器（N = 100 ~ 160）
N = 120 -> 惯量暴增 14,400 倍！静摩擦占额定力矩 20%~30%，外力全卡死在齿轮里，电机电流毫无感知！

想做真阻抗控制：两条硬件出路

  • 具身主流（低减速比行星 QDD）：大扭矩外转子电机配 6:1 ~ 10:1 行星齿轮，天生丝滑可反驱，直接跑 MIT / CST 阻抗，抗冲击且成本可控。
  • 旗舰协作臂（每轴加关节扭矩传感器 JTS）：如 Franka Research 3、库卡 iiwa，保留 100:1 谐波减速器，但在每个关节输出端塞入扭矩传感器做内环摩擦力抵消，手感极佳但造价高昂。

存量传统工业臂：腕部六维力 + 导纳破局

  • 高性价比工程方案：既然 6 个谐波/RV 关节内部摩擦糊死了，干脆保留驱动器原有的高刚性 CSP 位置模式不动。
  • 只需在最末端手腕法兰盘加装 1 颗六维力传感器（测三维力 Fx,Fy,Fz 与三维力矩 Mx,My,Mz），用外层导纳算法实时修正目标位置，即可低成本实现精密插拔与恒力打磨。
追问 2 展厅里一根小拇指就能牵着走的“零力拖动示教”，底层代码到底是怎么写的？

让几十斤重的金属手臂像羽毛一样悬浮在半空任人牵引，工程上对应“纯动力学电流前馈派”与“腕部传感器零力导纳派”两种标准写法：

# 写法 1：QDD / 协作机械臂 —— 纯动力学重力矩 + 摩擦力前馈补偿（CST 模式，Kp=0, Kd=0）
tau_gravity  = pinocchio.computeGeneralizedGravity(model, q_actual)         # 实时计算各轴重力矩 G(q)
tau_friction = K_coulomb * tanh(dq_actual / v_eps) + K_viscous * dq_actual  # 抵消静摩擦与粘滞阻尼
tau_cmd      = tau_gravity + tau_friction                                   # 全身任意连杆均可一指推走

# 写法 2：带腕部六维力传感器的工业臂 —— 目标力为 0 的纯阻尼导纳控制（CSP 模式）
F_human      = read_wrist_ft() - rotate_tool_gravity_to_sensor(q_actual)    # 剥离末端夹爪自重分量
v_cartesian  = F_human / B_virtual_damping                                  # 人往哪拉，指令点就往哪走
q_des_next   = q_actual + damped_pinv(Jacobian(q_actual)) @ v_cartesian * dt

✓ 写法 1（动力学前馈）：全臂柔顺

  • 无论你推手腕、推小臂还是推手肘，整条机械臂都能顺滑让开；但对连杆质量、质心坐标与温度漂移下的摩擦模型精度要求极高（参数偏 5% 就会出现松手慢速下坠或自发漂移）。

⚠ 写法 2（腕部零力导纳）：仅工具端可拉

  • 哪怕是负载 200 kg 的重型工业机械臂，握住末端工具也能用一根手指轻松牵引；但传感器后方的手臂本体完全没有测力能力，如果去推大臂或手肘依然像铁墙一样纹丝不动。
追问 3 调试机械臂时总被警告“避开奇异点（Singularity）”，奇异点到底是什么？为什么会暴走？

不用死记线性代数里的“雅可比矩阵降秩 det(J) = 0”，用你自己的手臂做个动作 3 秒钟就能建立物理直觉：

⚠ 物理现象：自由度丢失与分母归零速度爆炸

  • 边界伸直奇异：把胳膊 180° 彻底绷直，外力顺着手臂往回推你时全靠骨头硬顶（电机不用出力），但你想让手掌再往前伸 1 毫米也做不到——丢失了沿手臂方向的运动能力。
  • 腕部共线奇异（最危险）：当六轴机械臂第 4 轴与第 6 轴旋转中心重合（类似万向节死锁），手掌明明只想匀速缓慢平移走直线，逆运动学求逆 dq = J⁻¹·v 时因除以趋近于 0 的数，会瞬间命令第 4、6 关节以每秒数千度的极限转速疯狂甩尾翻转 180°！

✓ 工程破局：MoveJ 绕行与阻尼最小二乘（DLS）

  • 区分 MoveJ 与 MoveL：在关节空间直接插值角度（MoveJ）根本不求雅可比逆矩阵，绝对不会触发奇异点暴走；只有强制要求笛卡尔走直线（MoveL）或跑导纳控制时才会踩坑。
  • 阻尼最小二乘伪逆（Damped Least Squares）：将 J⁻¹ 替换为 Jᵀ(JJᵀ + λ²I)⁻¹——接近奇异区时自动注入微小阻尼项 λ² 托底分母，宁可让直线轻微弯曲 1 毫米，也绝不允许关节速度无穷大爆炸。
Part 04 · 三大机械臂硬件门派与全概念选型速查
面对传统工业臂、协作臂与准直驱具身机械臂，算法栈该如何对号入座？

Jacobian Jᵀ(q)		 力映射核心 连杆实时几何姿态 靠公式 τ = Jᵀ · F 把“手掌想出的空间推力”直接换算成“每个关节电机的目标力矩”。
奇异点
Singularity		 几何死锁禁区 雅可比降秩 det(J)=0 手臂完全绷直或轴线重合：丢失某方向运动能力，强行走直线会导致关节目标转速无穷大暴走。
被动柔顺
Passive Compliance		 物理缓冲派 机械弹簧 / 橡胶 / RCC 柔顺腕 真装物理弹簧：零延迟、便宜耐造，适合流水线倒角轴孔盲插；但刚度写死无法代码在线修改。
阻抗控制
Impedance Control		 主动柔顺 · 哥哥 CST / MIT 力矩关节（或 JTS） 测位置差 → 算出力矩：真弹性肌肉，不怕高速猛撞；人形机器人、四足、QDD 机械臂绝对主力。
导纳控制
Admittance Control		 主动柔顺 · 弟弟 CSP 位置电机 + 腕部六维力 测外力 → 修改目标位置：硬汉贴痛觉神经主动退让，让高减速比传统工业臂胜任精密柔顺装配。
力位混合控制
Hybrid Force/Pos		 接触作业王牌 正交选择矩阵 + 力闭环 擦黑板绝活：垂直曲面死守恒定 15N 按压力，平行曲面精准走轨迹；手机壳抛光、焊缝打磨必备。
直接力控制
Direct Force		 纯力闭环 力传感器 + 力矩/位置内环 不关心停在哪，只管末端压紧力严格跟踪设定牛顿数；用于恒力压装机、材料疲劳测试台。
重力补偿
Gravity Comp G(q)		 动力学基本功 连杆质量质心参数 + CST 太空失重悬停：电机实时输出刚好抵消自身重量的反向力矩，松手即稳稳停在半空不砸桌。
零力拖动示教
Lead-through		 零代码编程 重力+摩擦补偿 或 零力导纳 手把手教徒弟：老师傅握着机械臂走一遍焊接或涂胶路线，自动记录毫秒级点位并无限精准重播。
六维力 vs 关节扭矩
6-Axis F/T vs JTS		 测力硬件选型 应变片 / 光学电容测力计 腕部六维力：手腕装 1 颗测末端六维力/矩；关节扭矩 JTS：每轴装 1 颗（共 6~7 颗），全臂防撞。
